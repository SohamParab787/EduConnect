# 🎓 EduConnect – Education CRM System

EduConnect is an Education Customer Relationship Management (CRM) system developed to streamline student data management, course sales, customer support, and lead tracking for educational institutions.

## ✨ Features

### 👨‍💼 Admin Module
- Secure login and profile management
- Employee management (add, view, update)
- Course management (add, view, update, delete)
- Customer management and search
- Sales monitoring and analytics
- Feedback collection and analysis

### 👩‍💻 Employee Module
- Secure login and profile management
- Handle customer inquiries
- Manage leads and interested students
- Track discussions and follow-ups

### 🎓 Customer Module
- Student registration and login
- Browse available courses
- Purchase courses
- Submit feedback

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript, jQuery, Bootstrap, AJAX
- **Backend:** Java, Spring Boot, Spring Web MVC
- **Database:** MySQL
- **ORM:** Spring Data JPA

## 🗄️ Database

The project uses MySQL to manage application data, including:

- **Register:** Admin and employee account details
- **Customer Register:** Student information
- **Sales:** Course purchases, prices, and transaction dates
- **Customer Inquiries:** Interested courses, discussions, and follow-up details

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/SohamParab787/EduConnect.git
cd EduConnect
```

### 2. Configure the Database

- Create a MySQL database.
- Update the database URL, username, and password in `application.properties`.
- Ensure the database configuration matches your local MySQL setup.

### 3. Run the Application

Open the project in your preferred Java IDE and run the main Spring Boot application class.

Alternatively, if Maven is configured:

```bash
mvn spring-boot:run
```
